🌐 Network Topology

Inception Bridge Network

Tüm servisler özel bridge network üzerinde izole şekilde çalışır:

  • Internal Communication: Container isimleriyle DNS resolution
  • External Access: Sadece NGINX (443) ve FTP (21) portları exposed
  • Security: MariaDB ve Redis sadece internal network'te erişilebilir
  • Isolation: Her konteyner kendi filesystem ve process space'ine sahip

💾 Volume Management

Volume Name Host Path Container Mount Purpose Driver
wordpress /home/login/data/wordpress /var/www/html WordPress files, plugins, themes local (bind)
mariadb /home/login/data/mariadb /var/lib/mysql Database files & tables local (bind)

✨ Persistence Benefits

Bind mount volumes sayesinde:

  • Container yeniden başlatıldığında veri kaybolmaz
  • Host üzerinden doğrudan dosyalara erişilebilir
  • Backup ve restore işlemleri kolaydır
  • Development sırasında hot-reload mümkündür

⚙️ Servis Detayları

ZORUNLU 1. NGINX Web Server

Base Image: debian:bullseye

Exposed Port: 443 (HTTPS only)

Internal Communication: wordpress:9000

📦 Kurulu Paketler:

nginx openssl

🎯 Görevler:

  • SSL Certificate Generation: OpenSSL ile self-signed certificate oluşturma
  • TLS Configuration: TLSv1.2 ve TLSv1.3 protokolleri aktif
  • Reverse Proxy: HTTPS isteklerini WordPress'e yönlendirme
  • FastCGI: PHP-FPM ile iletişim kurma
  • Static Files: CSS, JS, images için doğrudan serving

⚙️ Konfigürasyon Detayları:

server {
    listen 443 ssl;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_certificate /etc/nginx/ssl/nginx.crt;
    ssl_certificate_key /etc/nginx/ssl/nginx.key;
    
    location ~ \.php$ {
        fastcgi_pass wordpress:9000;
        include fastcgi_params;
    }
}

ZORUNLU 2. MariaDB Database

Base Image: debian:bullseye

Internal Port: 3306 (not exposed)

Volume: /var/lib/mysql (persistent)

📦 Kurulu Paketler:

mariadb-server mariadb-client

🎯 Görevler:

  • Database Initialization: mariadb-install-db ile ilk kurulum
  • User Management: Root şifresi + WordPress kullanıcısı oluşturma
  • Database Creation: WordPress için veritabanı hazırlama
  • Security: Anonymous users silme, test DB temizleme
  • Network Binding: 0.0.0.0'da dinleyerek container network'e açma

🚨 MariaDB Socket Hatası Çözümü

MariaDB 10.4+ sürümlerinde socket problemi yaşanabilir:

# Dockerfile'da
RUN mkdir -p /var/run/mysqld && \
    chown -R mysql:mysql /var/run/mysqld && \
    chmod 777 /var/run/mysqld

# Init script'te
chown -R mysql:mysql /var/run/mysqld

# mysql.user yerine mysql.global_priv kullan
ALTER USER 'root'@'localhost' IDENTIFIED BY '${PASSWORD}';

ZORUNLU 3. WordPress + PHP-FPM

Base Image: debian:bullseye

Internal Port: 9000 (FastCGI)

Volume: /var/www/html (shared with NGINX)

📦 Kurulu Paketler:

php8.2-fpm php8.2-mysql php8.2-cli php8.2-curl php8.2-gd php8.2-mbstring php8.2-xml php8.2-zip php8.2-redis curl mariadb-client

🎯 Görevler:

  • WP-CLI Installation: WordPress komut satırı aracı kurulumu
  • WordPress Download: wp core download ile son sürüm
  • Database Configuration: wp-config.php oluşturma
  • Site Installation: wp core install ile otomatik kurulum
  • User Creation: Admin + normal user oluşturma
  • Redis Integration: Object cache plugin kurma ve aktifleştirme
  • MariaDB Wait: Database hazır olana kadar bekleme mekanizması

⚙️ PHP-FPM Configuration:

# Socket yerine TCP dinle
sed -i 's/listen = \/run\/php\/php8.2-fpm.sock/listen = 9000/g' \
    /etc/php/8.2/fpm/pool.d/www.conf

# WordPress kurulumu
wp core install \
  --url="https://${DOMAIN_NAME}" \
  --title="${WP_TITLE}" \
  --admin_user="${WP_ADMIN_USER}" \
  --admin_password="${WP_ADMIN_PASSWORD}" \
  --admin_email="${WP_ADMIN_EMAIL}" \
  --allow-root

📄 script.sh - Ana Kurulum Script'i

script.sh

Bu script tüm proje yapısını, Dockerfile'ları, konfigürasyonları ve docker-compose.yml'i otomatik oluşturur.

1-3
#!/bin/bash
set -euo pipefail
Shebang & Error Handling:
  • #!/bin/bash: Bash interpreter kullan
  • set -e: Hata durumunda script'i durdur
  • set -u: Tanımsız değişken kullanımını engelle
  • set -o pipefail: Pipe içinde hata varsa yakala
11-18
if ! command -v docker >/dev/null 2>&1; then
echo "Docker yüklü değil"
exit 1
fi
Dependency Check: Docker ve Docker Compose'un yüklü olup olmadığını kontrol eder. Yoksa script hata vererek durur.
20-26
LOGIN=$(id -un)
DOMAIN_NAME="${LOGIN}.42.fr"
DB_ROOT_PASSWORD=$(openssl rand -base64 12)
Variable Initialization:
  • id -un: Mevcut kullanıcı adını al
  • Domain: kullanıcı.42.fr formatında oluştur
  • openssl rand -base64 12: 12 byte rastgele şifre üret (Base64 encode)

if [ ! -d "/home/${LOGIN}" ]; then
HOST_DATA_DIR="${HOME}/data"
fi

🐳 MariaDB Dockerfile

srcs/requirements/mariadb/Dockerfile
FROM debian:bullseye

RUN apt-get update && apt-get install -y \
    mariadb-server \
    mariadb-client \
    && rm -rf /var/lib/apt/lists/*

RUN mkdir -p /var/run/mysqld && \
    chown -R mysql:mysql /var/run/mysqld && \
    chmod 777 /var/run/mysqld

RUN sed -i 's/127.0.0.1/0.0.0.0/g' /etc/mysql/mariadb.conf.d/50-server.cnf

COPY tools/init_db.sh /usr/local/bin/
RUN chmod +x /usr/local/bin/init_db.sh

EXPOSE 3306

CMD ["/usr/local/bin/init_db.sh"]
1
FROM debian:bullseye
Base Image: Debian 11 (Bullseye) kullan. 42 subject gereksinimi: penultimate stable version.
3-6
RUN apt-get update && apt-get install -y mariadb-server...
Package Installation:
  • apt-get update: Package listesini güncelle
  • mariadb-server: MariaDB database server
  • mariadb-client: CLI tools (mariadb, mariadb-admin)
  • rm -rf /var/lib/apt/lists/*: Cache temizle, image boyutunu küçült
8-10
RUN mkdir -p /var/run/mysqld && chown...
Socket Directory Fix: MariaDB socket dosyasını /var/run/mysqld/'de oluşturur. Permissions olmadan "Can't connect through socket" hatası alınır.
12
RUN sed -i 's/127.0.0.1/0.0.0.0/g'...
Network Binding: MariaDB'yi 0.0.0.0'da dinle. Böylece container network'teki diğer servisler (WordPress) erişebilir. Default 127.0.0.1 sadece localhost demektir.
18
CMD ["/usr/local/bin/init_db.sh"]
Entrypoint: Container başladığında init script'i çalıştır. Bu script database'i initialize eder ve mariadbd daemon'ı başlatır.

💡 Docker Best Practices

  • Single RUN: Birden fazla komut tek RUN'da birleştirilerek layer sayısı azaltılır
  • Cache Cleanup: apt lists temizlenerek image boyutu küçültülür
  • Explicit Versions: bullseye tag ile version sabitleme
  • Non-root User: MariaDB mysql kullanıcısıyla çalışır (güvenlik)

🔧 Sorun Giderme

❌ Sık Karşılaşılan Hatalar

🔴 MariaDB Socket Hatası

Hata Mesajı:

Can't connect to local MySQL server through socket '/var/run/mysqld/mysqld.sock'

Sebep: Socket directory yok veya izinler yanlış

Çözüm:

# Dockerfile'a ekle
RUN mkdir -p /var/run/mysqld && \
    chown -R mysql:mysql /var/run/mysqld && \
    chmod 777 /var/run/mysqld

# Init script'te de kontrol et
chown -R mysql:mysql /var/run/mysqld

🔴 WordPress MariaDB'ye Bağlanamıyor

Hata Mesajı: "Error establishing a database connection"

Sebep: MariaDB hazır değilken WordPress başlamaya çalışıyor

Çözüm 1 - Healthcheck:

mariadb:
  healthcheck:
    test: ["CMD", "mariadb-admin", "ping", "-h", "localhost"]
    interval: 10s
    timeout: 5s
    retries: 5
    start_period: 30s

wordpress:
  depends_on:
    mariadb:
      condition: service_healthy

Çözüm 2 - Wait Loop:

until mariadb -h mariadb -u"${DB_USER}" -p"${DB_PASSWORD}" -e "SELECT 1" >/dev/null 2>&1; do
  echo "Waiting for MariaDB..."
  sleep 2
done
echo "MariaDB is ready!"

🔴 NGINX 502 Bad Gateway

Hata Mesajı: 502 Bad Gateway

Olası Sebepler:

  • PHP-FPM çalışmıyor veya 9000 portunda dinlemiyor
  • WordPress container çalışmıyor
  • NGINX config'te yanlış upstream address

Debug Adımları:

# WordPress container çalışıyor mu?
docker ps | grep wordpress

# PHP-FPM 9000'de dinliyor mu?
docker exec wordpress netstat -tlnp | grep 9000

# NGINX config test
docker exec nginx nginx -t

# NGINX error log kontrol
docker logs nginx 2>&1 | grep error

Çözüm:

# PHP-FPM'i TCP modunda dinlet
sed -i 's/listen = \/run\/php\/php8.2-fpm.sock/listen = 9000/g' \
    /etc/php/8.2/fpm/pool.d/www.conf

🔴 Volume Permission Denied

Hata Mesajı: Permission denied when accessing files

Sebep: Host ve container arasında user ID mismatch

Çözüm:

# Host'ta dizinleri oluştur ve izinleri ayarla
mkdir -p ~/data/wordpress ~/data/mariadb
chmod -R 755 ~/data

# Container içinde doğru user kullan
chown -R www-data:www-data /var/www/html
chown -R mysql:mysql /var/lib/mysql

⚡ Performance İyileştirme

Öneriler:

  • Redis: wp redis enable --allow-root ile aktif et
  • PHP-FPM: pm.max_children değerini artır (default 5)
  • MariaDB: innodb_buffer_pool_size ayarla
  • NGINX: gzip compression ekle
  • Caching: Browser cache headers ekle
